Méthode 1: Page Admin (Recommandé)

La façon la plus simple de voir toutes vos soumissions

1 Ouvrir la page Admin

Allez sur http://localhost:8080/admin.html ou cliquez sur "Admin" dans le menu

2 Voir vos statistiques

Vous verrez le nombre total de soumissions, aujourd'hui, cette semaine et ce mois

3 Filtrer et rechercher

Utilisez la barre de recherche pour trouver un client par nom, email ou téléphone

4 Exporter les données

Cliquez sur "Export CSV" pour télécharger toutes les données en format Excel

Méthode 2: Console JavaScript

Pour les utilisateurs avancés

Ouvrir la Console

1 Appuyez sur F12

Ou clic droit → Inspecter → Console

Commandes Disponibles

Voir toutes les soumissions 
sichertechAdmin.getAllSubmissions()
Exporter en CSV 
sichertechAdmin.exportSubmissionsToCSV()
Chercher une soumission spécifique 
// Par email
const submissions = sichertechAdmin.getAllSubmissions();
const found = submissions.find(s => s.email === 'client@email.com');
console.log(found);
Filtrer par service 
// Toutes les demandes de web development
const submissions = sichertechAdmin.getAllSubmissions();
const webDev = submissions.filter(s => s.service === 'web-development');
console.log(`${webDev.length} demandes de web development`);
Filtrer par budget 
// Clients avec gros budget
const submissions = sichertechAdmin.getAllSubmissions();
const highBudget = submissions.filter(s => s.budget === 'over-50k');
console.log('Clients budget élevé:', highBudget);
Supprimer toutes les données (Attention!) 
sichertechAdmin.clearAllSubmissions()

Cherchez la clé sichertech_submissions

Options Avancées

1. Envoi par Email Automatique

Configurez EmailJS pour recevoir les soumissions par email:

• Créez un compte sur EmailJS.com
• Configurez votre service email
• Ajoutez les clés API dans js/main.js

2. Sauvegarde dans une Base de Données

Pour une solution professionnelle:

Options populaires:
• Firebase - Base de données en temps réel gratuite

• MongoDB Atlas - Base de données NoSQL

3. Webhook vers votre CRM

Intégrez directement avec:

• HubSpot - CRM et Marketing
• Salesforce - CRM entreprise
• Zapier - Connecteur universel
• Make (Integromat) - Automatisation

Exemples de Code Pratiques

Obtenir les 5 dernières soumissions

const submissions = sichertechAdmin.getAllSubmissions();

console.table(latest5);

Compter par service

const submissions = sichertechAdmin.getAllSubmissions();
const byService = {};
submissions.forEach(s => {
    byService[s.service] = (byService[s.service] || 0) + 1;
});
console.log('Statistiques par service:', byService);

Trouver les emails pour newsletter

const submissions = sichertechAdmin.getAllSubmissions();
const newsletters = submissions
    .filter(s => s.newsletter)
    .map(s => s.email);
console.log('Abonnés newsletter:', newsletters);

Exporter les téléphones pour WhatsApp

const submissions = sichertechAdmin.getAllSubmissions();
const phones = submissions.map(s => s.phone);
console.log('Tous les téléphones:', phones.join(', '));

Questions Fréquentes

Où sont stockées les données?

Les données sont stockées localement dans le localStorage de votre navigateur. Elles restent sur votre ordinateur et ne sont pas envoyées à un serveur.

Les données sont-elles perdues si je ferme le navigateur?

Non! Les données restent sauvegardées même après fermeture du navigateur. Elles sont conservées jusqu'à ce que vous les supprimiez ou vidiez le cache.

Combien de soumissions peuvent être stockées?

Le système garde les 50 dernières soumissions. Exportez régulièrement en CSV pour conserver un historique complet.

Comment sauvegarder mes données?

Utilisez le bouton "Export CSV" sur la page admin. Cela télécharge un fichier Excel avec toutes vos données que vous pouvez ouvrir et sauvegarder.

Puis-je accéder aux données depuis un autre ordinateur?

Non, les données localStorage sont spécifiques à chaque navigateur. Pour un accès multi-appareils, configurez une base de données (Firebase, Supabase, etc.)
